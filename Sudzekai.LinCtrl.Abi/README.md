# Sudzekai.LinCtrl.Abi

Native ABI descriptors, function tables, and buffer views for Sudzekai LinCtrl hosts and plugins.

```sh
dotnet add package Sudzekai.LinCtrl.Abi --version 0.2.0
```

Requires .NET 10 for runtime libraries and a compatible .NET 10 SDK for plugin generation.
