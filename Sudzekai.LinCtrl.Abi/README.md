# Sudzekai.LinCtrl.Abi

Нативные дескрипторы ABI, таблицы функций и представления буферов для хоста и плагинов LinCtrl.

```sh
dotnet add package Sudzekai.LinCtrl.Abi --version 0.4.0
```

Требуется .NET 10.

Исходный код доступен в [sudzekai-web-os/bundle](https://github.com/sudzekai-web-os/bundle). Лицензия Apache-2.0.
