# plugin-hosting-bundle

Набор библиотек для нативной (NativeAOT) интеграции плагинов с хостом через unmanaged-ABI.

## Проекты

- **Sudzekai.WebOs.Core** — общие типы, ABI-дескрипторы, интерфейсы хендлеров, DTO и перечисления.
- **Sudzekai.WebOs.Host** — хост: загрузка плагинов (`NativeLibrary`), регистрация обработчиков, интеграция с `WebApplication`.
- **Sudzekai.WebOs.Plugin** — сторона плагина: билдер плагина, конвертация DTO → дескрипторов, контейнер колбэков.

> **WIP** — рабочий прототип, API и ABI ещё меняются.
